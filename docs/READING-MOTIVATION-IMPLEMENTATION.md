# Reading motivation v1 implementation

## Scope and defaults

Implemented against `cursor/reading-motivation-v1` at base `08f6c965ce646d8816132ba5ef99f61be5a96f4c`. Fix-pass-5 corrections start from clean `73b8e4701926d39b719f52c7ac1cc8176651e6ec` (includes local timezone `0fd91b10` and Chief-approved macOS-only notification-name compatibility). The checkout was clean before edits and `origin` was `https://github.com/subarude15/storyteller-personal-reader.git`.

This base has no existing daily reading-goal setting in the Swift sources, so v1 starts at 30 minutes per day for reading and 30 minutes per day for listening. Goals accept 5–240 minutes. The local settings record defaults to three Home pins (Read today, This week, Current streak), reminders off, and a 20:30 quiet delivery time. Empty pin selections are supported and shown explicitly. Invalid goal values use the safe defaults; empty/malformed session data contributes zero progress.

Calendar days, week boundaries, quiet delivery, and displayed finish dates use the device's current calendar/time zone. Sessions are split at local midnight. A streak day requires valid recorded session time; the current count may end yesterday until today's activity is recorded (yesterday grace). Only sessions being removed by SessionTracker's one-year pruning are archived. Each archived identity freezes its local year/month/day plus source calendar/time-zone identifiers, is never rebucketed after travel, and is deduplicated against live session dates by its calendar-day key. The old v1 absolute-Date cache had no source calendar/time-zone identity and included retained sessions: migration rebuilds overlapping days from available sessions and freezes source-less markers as `legacy-UTC` date identities. Their original local label cannot be recovered without the old time zone; the migration keeps one stable identity per old marker and never rebuckets it again.

Historical streak references (for example prior-week Sunday night) clip sessions that start before the reference and end after it, keeping the valid earlier portion and clearing `endProgress` when clipped (no fabricated historical checkpoint). Wholly future sessions at real-now remain rejected.

Quiet-time pace/rescue candidates evaluate reading and listening goals independently, then arbitrate one daily kind (`rescue > pace > receipt`). Over-complete listening cannot suppress an unmet reading goal (and the converse). A morning launch can schedule tonight's reminder without later app interaction. Obsolete higher-priority pending kinds are replaced or cancelled when progress removes eligibility.

Continue widget snapshots store `streakActivityDayKey` with the streak count. Publish serializes read/preserve/write/signature under one lock so concurrent audio/Home updates cannot overwrite a fresher streak with a stale previous snapshot; `reloadTimelines` runs after unlock. Audio/session-end mirrors use `publishLiveMirror` and pass streak only when Home supplies authoritative values in that call; they never pre-read and re-assert stored streak outside the lock. `updateAuthoritativeStreak` updates only streak/anchor/`generatedAt` under the same lock and no-ops when streak data is unchanged. Display resolves today/yesterday grace and expires older streaks. `paintSignature` uses typed `[String]` intermediates (no overloaded `String.init` map) so Swift 6.2 can type-check it. Known elapsed with unknown duration paints via `elapsedLengthText` (`"Xm elapsed"`); ebook kind timing stays unknown.

`projectedFinish` returns `.finished` only for confirmed full progress (`>= 1`). Near-complete progress (e.g. 99.5%) with known length/rate still yields a remaining estimate; unknown metadata stays unknown (`nil`), not finished. Pace accounting still counts wall time across progress plateaus and missing mid-interval checkpoints, rejects regressions honestly, and guards the rounded-up second count against the first Int-unrepresentable bound (`2^63`) before conversion.

The notification coordinator transaction gate serializes callers only — not OS delivery. An injectable clock revalidates current time and delivered/expired pending state around cancellation/replacement so a late OS delivery of the old request consumes the day and blocks a same-day replacement. Fixed-date coordinator tests inject `TestMotivationClock` so `max(fixtureNow, clock.now())` is not wall-time dependent. `ingestDelivered` persists requested+actual consumed days before removing OS delivery evidence (UserDefaults save is best-effort; not a power-loss claim beyond that API). `pendingIdentifiers()` inspects real OS pending requests; restart recovery reinstalls a future unconsumed ledger pending that is missing from the OS (same stable identifier), after revalidating clock/deliveries/expiry, and never resurrects expired or already-delivered intents.

Active-session motivation cadence is owned by `SessionTracker` (not the Home 30s stats timer): start/restore starts a 30s loop that publishes authoritative streak+activity after the minimum 30s retention (and on day-change / retained end) whether or not notifications are enabled; notification reconcile stays independently gated on opt-in. End/stop (including under-30s paths) cancels the task; retained ends also publish streak. Foreground `scenePhase == .active` restores the loop and refreshes once. **OS limit:** iOS may suspend or delay timer ticks in the background; arbitrary suspension is not claimed to keep the widget fresh until foreground restore.

## Final consistency follow-up

- Authoritative streak publication returns success (including an already-matching persisted snapshot). SessionTracker caches only success, so no-container/no-item/write failures remain retryable; a regression creates the snapshot after the first failed attempt.
- Home passes its live audio snapshot into projection. Matching audio/podcast items use current elapsed, duration and rate from that same snapshot, not a stale queue fraction; mismatched items do not inherit its timing and unknown live duration stays unknown. Pure shared-policy regression covers live timing overriding stale progress and item mismatch.
- A legacy pending intent without a fire date is ambiguous after dismissal. Reconciliation conservatively consumes its requested day and current day, persists before OS cancellation, and declines another notification rather than risk a duplicate. This may suppress a reminder for one day on legacy migration.
- Expired pending records with absent OS evidence also conservatively consume the current local day, covering a notification delivered late across midnight then dismissed. The consumed ledger is saved before cancellation can suspend. Parameterized regression covers both undated legacy and dated previous-day pending records.
- Home now supplies a synchronous main-actor streak provider, invoked after all session/artwork awaits immediately before the locked write. This avoids overwriting a SessionTracker refresh with pre-await streak scalars. The iOS-only publisher has a source-ordering integration assertion, not claimed macOS runtime/device coverage.
- Fractional forecast seconds are preserved after the existing finite/Int-bound guards, avoiding rounding floating-point noise into an extra second at99.5% completion.
- Actual native run43722803493 compiled the production package, then found test-helper internal-access failures; the widget test module now uses standard `@testable import SilveranAppleWidgets`. Normal iOS run43722803486 succeeded on087b96a7. Later changes require a fresh exact-tip native/normal run; these earlier results are not claimed for the new tip.
